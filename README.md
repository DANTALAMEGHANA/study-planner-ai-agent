# Smart Study Planner AI Agent 🧠📚

This project is a Python-based AI agent that helps students create an intelligent study plan based on subject difficulty, exam date, and available study time.

## Features
- Takes subject difficulty as input
- Calculates remaining days until exam
- Allocates more study time to difficult subjects
- Simple AI decision-making logic

## Technologies Used
- Python
- datetime module

## How to Run
1. Clone the repository
2. Run the program:
   ```bash
   python study_planner.py
